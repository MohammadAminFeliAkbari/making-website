# قالب آغازین وب‌سایت

قالبی قابل استفادهٔ مجدد با React و TypeScript که با Vite، Tailwind CSS، React Router و آیکون‌های Lucide ساخته شده است. برای سازگارکردن قالب با پروژهٔ جدید، پیکربندی مرکزی و محتوای صفحه‌ها را ویرایش کنید.

## پیش‌نیازها

- Node.js نسخهٔ 20.19 به بالا یا 22.12 به بالا
- npm

## نصب

```bash
npm install
```

## اجرای محیط توسعه

```bash
npm run dev
```

نشانی محلی برنامه در ترمینال Vite نمایش داده می‌شود.

## بررسی TypeScript

```bash
npm run typecheck
```

## ساخت نسخهٔ نهایی

```bash
npm run build
npm run preview
```

## ساختار پروژه

- `src/config/site.ts` — نام وب‌سایت، توضیحات، پیمایش، اطلاعات تماس، رنگ اصلی و پیوندهای شبکه‌های اجتماعی.
- `src/pages/` — صفحه‌های مستقل مسیرها.
- `src/components/common/` — اجزای مشترک مانند دکمه، ظرف محتوا و عنوان بخش.
- `src/components/layout/` — سربرگ، پابرگ و پوستهٔ صفحه.
- `src/components/sections/` — بخش‌های قابل استفادهٔ مجدد صفحهٔ اصلی.
- `src/styles/index.css` — نقطهٔ ورود Tailwind، توکن‌های طراحی و سبک‌های سراسری.
- `public/images/` — تصویرهای پروژه را در این پوشه قرار دهید.

فرم تماس در مرورگر اعتبارسنجی می‌شود و پیام تأیید نشان می‌دهد. این فرم اطلاعاتی به سرور ارسال نمی‌کند.
